## Insights/Ideas
- 06:40 — NULL-collapsing refactor trap: merging a flag plus its gated date into one NULL-able column looks equivalent but is not. The consumer's CASE falls through on the NULL, so the "flagged but value missing" state silently gets the unflagged branch's value. The safe merge pushes the branch into the producer CTE (flag picks source A or B), never into the consumer's condition.
- 08:20 — Oracle SELECT-list alias trap: a SELECT-list alias is invisible to sibling expressions in the same SELECT. A gated value defined as an alias stays dead code while the consumers keep reading the raw column. The fix is a dedicated CTE layer that projects only the gated value. Signature: a computed alias with zero downstream consumers (the round-2 panel's blocker, finding _19).
- 08:20 — A/B diffs cannot prove a key fix on already-loaded rows. The interface dedup suppresses re-emission, so the fixed keys never appear in the diff. Verify key fixes on fresh QA data or after clearing the loaded rows. Signature: an expected A/B flip that never shows (the FIN-006 multi-line delivery case).
- 09:33 — fusion-sql exits 1 with "no RESULT element" on a zero-row result, so an empty A/B side reads as a failed run in shell output. Confirm the err log shows the right target pod, an empty `<G_1/>` group, and no `ORA-` before treating rc=1 as an error.
- 09:45 — BIP report-service date params must match the data model's declared mask (`MM-dd-yyyy` for the PoD DM). An ISO string mis-parses silently: the report echoes scrambled dates and returns zero rows with exit code 0. Check the echoed `<P_FROM_DATE>` before trusting an empty result.
- 09:55 — The Drive comments API lags the Docs UI in both directions. A comment posted in the UI can be invisible to the API (and to the local sidecar sync) for about an hour. A post missing from one sync is not a failed post; re-sync before reposting or duplicates land.
- 17:10 — OIC scheduled integrations do NOT serialize instances: a new run starts while the previous one still executes (user-confirmed). A report→apply chain slower than the schedule interval can double-read uncommitted work. Size lookbacks and apply idempotency for it.
- 17:10 — BIP `_datamodel.xdm` raw CDATA equals the repo `.sql` byte-for-byte. An XML `el.text` extraction adds a `\n`+12-spaces prefix and a `\n`+9-spaces suffix (23 bytes). Compare against the raw slice only. Codified in fusion-sql's `xdm_set_sql.py` / `xdm_verify_sql.py`.
