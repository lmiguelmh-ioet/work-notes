## Insights/Ideas
- 09:38 — RP_ARB returns an empty `<G_1/>` (not a RESULT element) when the query yields zero rows. fusion_sql then reports "ERROR: no RESULT element in report output". An empty result is a successful run, not a failure.
- 09:38 — The RP_ARB `:p_sql` bind is VARCHAR2 (32,767 chars). A larger DM fails with ORA-01460. Strip comments from the query before a spot-check run.
- 10:27 — `ra_batch_sources_all` joins to `ra_customer_trx_all` on `BATCH_SOURCE_SEQ_ID`, not `BATCH_SOURCE_ID` (ORA-00904 "invalid identifier" otherwise).
- 10:27 — `VRM_SOURCE_DOC_LINES.DATA_TRANSFORMATION_STATUS` vocabulary on dev1: NOT_PROCESSED (in-flight), PROCESSED, REJECTED, UPDATE_PROCESSED, UPDATE_REJECTED. U-record writes land as NEW version rows; the original version-flag row never carries them.
- 10:27 — Comparing a stored interface-table date (midnight) with a computed Oracle date (time component) needs TRUNC on both sides. A raw `<>` re-fires on the same calendar day forever.
- 12:45 — OIC's ad hoc "Run now" dialog restores the last-used parameter value when a field is left empty. Clearing the field is impossible. A garbage value (`''`) sticks and makes a safe negative test: the scoped report returns zero rows, nothing is applied, and the fixture is not consumed.
- 12:45 — Conditional node omission in the OIC mapper is a UI-only recipe: drag `if` from XSL Constructors → Flow Control onto the target node as its PARENT. Child placement emits an empty element instead, and a blank string reaches the endpoint.
