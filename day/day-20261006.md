## Insights/Ideas
- Direct BIP report SOAP call: needs `-H "Content-Type: application/soap+xml; charset=utf-8"` (SOAP 1.2 — `text/xml` fails with VersionMismatch) and `curl --compressed`; response base64 in `reportBytes`.
- PoD dedup boundary: dedup joins on `document_line_id`, so it engages only AFTER transformation — the ~4 min INITIALIZED window does not suppress re-extract.
- ott front doors: stage `oic` IAM user and wp-primary SSO roles all get 403 on ott InvokeFunctionUrl; only `oic2` works locally (custom-auth HMAC Lambda is the CI path).
- sync.py sidecar loss: a Drive-body change + comments-fetch 403 in the same run silently deleted `.comments` sidecars (the keep-on-failure guard only covered unchanged files). Fixed by staging the previous sidecars from dest before fetching. Log gotcha: `cmd 2>&1 | tail` shows stderr warns BEFORE all stdout lines — Python block-buffers stdout when piped.
- oracle-integration-cloud convention: a report PR merges only when the report is promoted to PROD — `main` mirrors prod state, so an open approved PR means "validated, awaiting the prod move", not a stalled review. Recorded in the repo's AGENTS.md (Development Workflow step 6).
- `cp -R src/ dest` with a trailing slash on the SOURCE merges the source's contents into dest and clobbers same-named files (it wiped `monocle_integrations/__init__.py`). Recover with `git checkout -- <files>` + remove stray dirs; copy package trees with `rsync -a src/ dest/pkg/` instead.
- Subagent proposals built from a stale branch checkout can silently revert newer `main` additions (caught it in barrel `__init__.py` files losing `_hcm`/FedEx exports). Diff every generated barrel against `main` before applying.
- mypy strict `comparison-overlap` rejects `EnumMember == "literal"` in BOTH directions — so with plain `Enum` (not `str, Enum`) the compiler itself bans `record.status == "FAILED"` repo-wide; no test pin is possible or needed.
- isort quirk in monocle_integrations: `pyproject.toml` sets `profile = "black"` with no `line_length`, so isort wraps imports at the black-profile default 88, not the repo's 99. Signature: `make format` rewraps a hand-written 89–99-char import into multi-line form.
- Shared Dynamo mapper precedent for 2+ readers on one table: a dedicated `_mappers.py` with module-level `from_item`/`to_item`, imported as `from .. import _mappers`, never barrel-exported. Example: `_adapters/_aws/_dynamodb/_inbound_inv_txns/`. OTCM-139192 PR 4/5 follows it.
- aioboto3 resource metadata is awaitable: `await table.key_schema` and `await table.global_secondary_indexes` auto-load the table, no explicit `load()`. Signature: the attribute prints as `<coroutine object ...property_loader...>`. In tests, AsyncMock children are not awaitable (`'AsyncMock' object can't be awaited`). Use a fake with `@property async def`.
- Python 3.14 `json.loads` survives ~2000 nesting levels. RecursionError needs ~200k. To test a RecursionError path, patch the parser: `mocker.patch("json.loads", side_effect=RecursionError)`.
- pytest landmine: `_easypost/_tracker/conftest.py` declares `pytest_plugins` in a non-top-level conftest. It loads only through the `make test-unit` file-list invocation. A directory arg that includes it fails collection (42 errors).
