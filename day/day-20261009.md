## Insights/Ideas
- 14:34 — CloudWatch Insights regex `parse` takes no `as` clause. The named group supplies the field. Signature: `MalformedQueryException unexpected symbol found as`. Use glob parse or a named regex group only.
- 10:09 — pytest run from the repo root can import the main checkout instead of a `tmp/` scratch worktree. The app root sits on `sys.path` first. Signature: coverage report shows 0% and file paths without the `tmp/` prefix. Run worktree checks with the worktree as cwd.
- 11:10 — The Read tool adds `   NN|` line markers at every 10th line of the chunk an agent receives. The markers are rendering metadata. They are not in the file. Signature: an agent claims a file you just edited contains `10|` paste artifacts. Run `rg -n '^\s{0,6}\d+\|' <file>` before you believe it. A clean result means the file is fine. Rule created at `~/.cursor/rules/read-chunk-line-markers.mdc`.
