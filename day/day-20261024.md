- 21:14 — Bash `${var:-{}}` appends a literal `}` when var IS set (the first `}` ends the expansion); write `${var:-"{}"}`. Signature: `jq: parse error: Unmatched '}'` right after adding an empty-default for a JSON var.

- 22:30 — `echo "$DATA" | python3 - args <<'PY'` silently loses the pipe: the heredoc owns stdin, so `json.load(sys.stdin)` dies `JSONDecodeError: Expecting value: line 1 column 1`. Pass the data via a temp file or argv.
