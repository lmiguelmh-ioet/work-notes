## Insights/Ideas
- 10:25 — Jinja2 attribute access on a dict hits dict methods first. `{{ row.values }}` resolves the dict's `.values()` method, not a `values` key, and the template fails with `TypeError: 'builtin_function_or_method' object is not iterable`. Rename the key (for example `entries`).
- 10:25 — Jinja2 `| join("<br>")` under autoescape escapes the separator too, so multi-value rows render a literal `&lt;br&gt;`. Use a `{% for %}` loop with a literal `<br>` and `loop.last` instead.
- 15:44 — On OIC's monitoring and errors endpoints, `totalResults` is capped at the page size. `totalRecordsCount` carries the true filtered total (itself capped at 10000 on the retention window). Signature: a list call reports "N of 10" while paging keeps returning more rows.
- 15:44 — A minted OAuth token is not proof of API access. OIC's edge rejects a token whose scope GUID does not match the instance: 401 with an empty body and no opc-request-id. A token that reaches OIC gets a JSON `NotAuthenticated` body instead. The two 401 shapes locate the refusal.
- 15:44 — `invalid_client` with "The OAuth Client app is inactive or the OAuth Client facet is not enabled" means the IDCS app exists but is deactivated. It is not a wrong client secret.
- 16:50 — GitHub review comments cannot anchor to lines outside the diff, including context lines that fall between two hunks. Signature: `add_comment_to_pending_review` fails with "The line number doesn't exist in the pull request diff". Anchor to the nearest in-diff line instead.
- 17:12 — OIC's monitoring and errors REST docs render payload keys kebab-case, but the live wire answers camelCase-only on all three probed endpoints. Docs are not wire truth. Probe before writing wire aliases.
- 17:12 — Rebasing a stacked branch onto its amended base with plain `git rebase <base>` replays the old base commit and add/add-conflicts every shared file. Use `git rebase --onto <new-tip> <old-tip> <branch>`.
