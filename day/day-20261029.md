## Insights/Ideas
- 08:39 — `str(RequestValidationError)` appends the raise-site traceback frame with absolute file paths (FastAPI 0.134). Signature: a 422 body carrying `File "/..."` lines. Probe exception text on live-raised errors; hand-built instances carry no traceback.
- 08:39 — `jsonable_encoder` raises on non-UTF-8 bytes and bare objects instead of stringifying them. Signature: `ValueError`/`UnicodeDecodeError` from inside an error handler. Use `json.dumps(..., default=str)` when the encode must never crash.
- 09:31 — Mangum 0.17.0 runs the FastAPI lifespan shutdown at the END of EVERY REST invocation, not at container shutdown (`Mangum.__call__` enters a fresh `LifespanCycle` per call). Signature: a lifespan shutdown handler (e.g. `close_all_sessions`) firing per request in a warm container. Verify against the Mangum source before assuming lifespan means container lifetime.
- 09:31 — A failure test that asserts only outcomes (error identity, await count) stays green under the old `asyncio.gather` it guards against, because gather runs both tasks before raising. Signature: the regression test passes when the fix is reverted. Block the second task on an Event mid-flight and assert `not run.done()`.
