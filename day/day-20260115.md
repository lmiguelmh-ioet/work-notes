## Questions relevant to MFG-I-3021

### 1. AI Frames and AI Accessories class codes

Relevant. The FSD (line 140) states:

> "There will be multiple files sent for 1 Work Order (i.e., 1 file with AI Frames, 1 file with Lenses)"

The class code mismatch (Smart_Frames vs AI Frames, AI_Accessories_Item_Class vs AI Accessories) could affect item identification if the integration relies on class codes. The FSD mapping (line 172) says:

> "Scale will send UPC; get Oracle Item Number based on UPC"

So the mapping uses UPC → Oracle Item Number, not class codes. However, if item class is used elsewhere in validation or processing, this discrepancy could cause issues.

### 2. WMS-I-1003 (ASN) — duplicate item detection

Potentially relevant. If the same AI Frames/Accessories item appears multiple times in a shipment and isn't summed, the same could occur in material issue payloads. The FSD doesn't specify handling for duplicate items in the same work order. Consider adding validation to detect and handle duplicates.

### 3. WMS-I-1005 (Pick Confirmation)

Highly relevant. This is the source integration for MFG-I-3021. The FSD (line 152) states:

> "The Pick Confirmation for Work Orders will be sent in a separate file from Transfer Order/Sales Order Pick Confirmation"

Any changes to pick confirmation logic could affect material issue.

### 4. MFG-I-3012, 3013, 3016 (Work Order integrations)

Relevant. Material issue operates on work orders, so work order creation/outbound logic could affect what material issue receives.

## Questions not directly relevant to MFG-I-3021

- Country of Origin validation — not in the material issue mapping

- LotControlled field appearing twice — not in the FSD mapping table

- SerialNumberTrackingOutbound appearing twice — not in the FSD mapping table

- UserDefined1 field — not in the FSD mapping table

- WMS-I-1006, 1007 — different integrations

- IT-I-2018, PO-I-2054-B — different integrations

- MFG-I-3022 — work order completion, different from material issue

## Recommendations for MFG-I-3021

1. Add validation for duplicate items: if the same AI Frames/Accessories item appears multiple times in the same work order payload, log a warning or create a JIRA ticket (as suggested for WMS-I-1003).

2. Verify item class handling: confirm whether item class codes are used anywhere in the material issue flow, even if the mapping uses UPC.

3. Document assumptions: the FSD doesn't address duplicate items or item class validation; document how these should be handled.

The current implementation processes all WorkDetails for a work order without checking for duplicates or validating item classes, which aligns with the FSD but may need enhancement based on these questions.
